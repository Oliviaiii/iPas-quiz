# iPAS AI 應用規劃師刷題工具

本專案預計製作一套可在瀏覽器使用的簡易刷題工具，範圍只包含經濟部
iPAS「AI 應用規劃師」初級與中級。

- 線上網站：https://oliviaiii.github.io/iPas-quiz/
- GitHub：https://github.com/Oliviaiii/iPas-quiz

目前已完成可部署的基礎架構及 114～115 年初級／中級場次盤點。盤點截止
2026-07-29，可確認的匯入目標為 600 題歷屆考題及 115 題最新版官方樣題，
共 715 題。

網站目前已收錄 450 題官方公告試題：

- 初級 114 年第四次：第一科「人工智慧基礎概論」50 題、第二科「生成式 AI
  應用與規劃」50 題。
- 初級 115 年第一次：第一科 50 題、第二科 50 題。
- 初級 115 年第二次：第一科 50 題、第二科 50 題。
- 中級 114 年第二次：第一科「人工智慧技術應用與規劃」、第二科「大數據處理
  分析與應用」、第三科「機器學習技術與應用」各 50 題。
- 題目與答案已逐頁對照官方 PDF。
- 點選選項後會鎖定答案並顯示答對／答錯及正確答案；已有實質內容的題目會
  另外顯示 A～D 選項解析。
- 可依科目篩選、只看錯題，作答進度保存在瀏覽器本機。

本站詳解是 AI 輔助撰寫的初稿，不是官方詳解。目前只有 114 年第四次人工智慧
基礎概論第 2～4 題已有實質 A～D 解析，其餘 447 題只顯示官方答案，待第二階段
逐題撰寫；不使用模板句假裝詳解已完成。原有 4 題非官方介面示範題已全部移除，
不列入題庫及統計。

目前可用功能：

- 初級及科目篩選。
- 點選選項後鎖定答案。
- 答對／答錯提示；完成撰寫的題目提供 A～D 選項詳解。
- 錯題篩選與瀏覽器本機進度。
- 手機與桌面響應式版面。

## 核心原則

1. 官方來源優先，第三方網站只能協助發現資料或交叉檢查。
2. 「題目已收錄」、「答案已核對」與「詳解已複核」是三種不同狀態。
3. 不把自行撰寫的解析稱為官方詳解。
4. 不整批複製第三方網站、補習班或出版品的解析。
5. 每一題都必須能追溯到原始來源文件及頁碼。
6. 題庫完整度必須由來源清冊和自動檢查證明，不能只靠人工印象。
7. 題庫建置進度只保留在專案文件，不在刷題網站公開顯示進度卡片。
8. 每完成一批題目、詳解或部署，必須同步更新來源清冊與交接文件。
9. 目前只執行第一階段題目匯入；715 題全部匯入並核對前，不開始批次詳解。

## 本機開發

```powershell
npm.cmd install
npm.cmd run dev
```

驗證：

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
```

靜態輸出位於 `out/`。GitHub Pages 部署由
`.github/workflows/deploy-pages.yml` 自動執行。
