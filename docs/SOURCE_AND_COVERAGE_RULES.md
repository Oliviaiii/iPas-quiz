# 資料來源與收錄規則

## 1. 來源優先順序

由高至低：

1. iPAS 官方公告、正式試題 PDF、答案及勘誤。
2. iPAS 官方樣題、評鑑內容範圍及學習指引。
3. 技術或法規的一手資料，例如主管機關、標準組織、原始論文及官方文件。
4. 第三方題庫，只能用來發現可能遺漏的文件或交叉檢查，不作為官方身分證明。

第三方網站出現、但官方來源尚未找到的題目，先放入待查清單，不得直接匯入
正式題庫。

## 2. 來源清冊必要欄位

每份來源文件至少記錄：

| 欄位 | 說明 |
| --- | --- |
| `sourceId` | 穩定且唯一的來源 ID |
| `title` | 官方文件完整標題 |
| `sourceType` | `official-exam`、`official-sample`、`official-correction` |
| `level` | `elementary` 或 `intermediate` |
| `subjectCode` | 專案定義的科目代碼 |
| `rocYear` | 民國年度；不適用時為空 |
| `session` | 梯次或版本；不適用時為空 |
| `examDate` | 考試日期；樣題可為空 |
| `publishedAt` | 公告日期；找不到時註明未知 |
| `url` | 官方原始網址 |
| `retrievedAt` | 本次取得或確認日期 |
| `expectedCount` | 官方文件中的題目數 |
| `importedCount` | 已匯入題數 |
| `availability` | `published`、`not-found`、`scheduled`、`superseded` |
| `inclusion` | `target` 或只作版本查核的 `audit-only` |
| `answerVerifiedCount` | 已逐題對照官方答案的題數 |
| `explanationDraftCount` | 已有自編詳解初稿的題數 |
| `explanationReviewedCount` | 詳解已完成人工複核的題數 |
| `notes` | 勘誤、重複文件、版面異常或其他說明 |

如果官方網站同一文件有多個網址，指定一個主要網址，其他網址放在別名清單；
不能因此重複匯入題目。

## 3. 官方題目判定

只有官方文件本身明確呈現題幹及選項，才能標記為官方題目。

- 官方正式考試公告：`sourceType = official-exam`
- 官方明確稱為樣題：`sourceType = official-sample`
- 官方答案更正：更新答案來源，並保留原答案與異動紀錄
- 一般學習內容：不能因為內容像題目就自動視為官方樣題

官方網站公開可讀不代表第三方解析可以自由複製。公開部署前仍應檢查官方使用
條款與必要的來源標示方式。

## 4. PDF 擷取規則

自動擷取只是初稿，不是完成。

每份 PDF 必須：

1. 保存或記錄原始官方網址。
2. 逐頁渲染檢查，不能只讀文字抽取結果。
3. 核對題號、答案、選項順序及跨頁內容。
4. 保留專有名詞、英文縮寫、數學符號及程式碼。
5. 表格、圖片或圖表需建立獨立素材，並記錄來源頁碼。
6. PDF 中的頁首頁尾不得誤併入題幹。

允許修正明顯的排版問題，例如移除換行造成的斷字；不允許在匯入時改寫題意。
若原題疑似有錯字，題目欄仍保留原文，另以編輯註記說明。

## 5. 題數與完整性檢查

每份試卷都要驗證：

- 匯入題數等於文件預期題數。
- 題號集合符合官方文件。
- 每題有題幹和必要選項。
- 答案為有效選項，或有特殊計分說明。
- 年度、梯次、級別與科目一致。
- 所有題目指回正確的 `sourceId`。

題號不連續不一定代表漏題；如果官方文件本身如此，必須在來源清冊註明，測試
也要依官方題號集合驗證，不能自行補號。

## 6. 重複題處理

同一題在不同年度或不同官方文件再次出現時：

- 若屬正式考試紀錄，原則上保留各次考試題目，因為來源與年度不同。
- 題目內容可以計算內容指紋，用於提示重複，但不能合併掉歷史紀錄。
- 若只是同一份 PDF 的鏡像網址，不得建立第二份題目。
- 統計「不重複題目數」時，必須與「歷次試題總題數」分開。

## 7. 來源衝突

答案依據順序：

1. 官方最新勘誤。
2. 官方正式答案。
3. 官方樣題答案。

若編輯者認為官方答案有爭議：

- 不得默默把正式答案改成自己認為正確的答案。
- 題目作答仍以最新官方答案為準。
- 在解析中加入「編輯註記」，清楚說明爭議與依據。
- 記錄查核者、日期及參考資料。

## 8. 盤點更新流程

目前專案先執行第一階段題目匯入。每份來源必須完成題幹、選項、官方答案、
來源頁碼及目視核對，才可計入第一階段完成數；新題的詳解狀態預設為
`missing`。第一階段固定盤點題庫全部完成前，不安排批次詳解。詳細門檻見
[題庫建置兩階段執行計畫](DELIVERY_PHASES.md)。

每次宣稱題庫已更新前：

1. 重新檢查 iPAS 官方 AI 應用規劃師的學習資源與公告頁。
2. 搜尋是否有新的試題、樣題或勘誤。
3. 更新來源清冊的 `retrievedAt`。
4. 匯入新增文件。
5. 執行完整性測試。
6. 更新題庫盤點截止日期與進度數字。

完整場次清單及當前數字見
[AI 應用規劃師題源與匯入進度](SOURCE_INVENTORY.md)。
