### 取得官方 PDF 需要的網路權限

官方 PDF 不進版控（`tmp/` 在 `.gitignore`），每次匯入都要重新下載。執行環境
必須允許連線至 `www.ipas.org.tw`（PDF 檔案）與 `ipd.nat.gov.tw`（歷屆考題與
樣題頁）；預設的 Trusted 連外等級不含這兩個網域，會在 CONNECT 階段被回 403。
在 Claude Code 環境設定選 Custom 並加入這兩個網域（同時保留預設套件庫清單）
即可。取得 PDF 後執行：

```sh
python scripts/fetch-official-pdfs.py <批次>
python scripts/import-official-exam.py <批次>
```

依 [SOURCE_AND_COVERAGE_RULES.md](SOURCE_AND_COVERAGE_RULES.md)，不得以第三方
整理的題目或答案替代官方文件，也不得憑記憶生成題目。

## 狀態定義

| `availability` | 意義 | 後續動作 |
| --- | --- | --- |
| `published` | 官方 PDF 已找到且題數已核對 | 擷取、逐頁校對、匯入、寫詳解 |
| `not-found` | 官方頁面目前沒有該文件：考試已舉行但未公告試題，或原本發布過、之後被官方下架 | 定期重查官方；第三方只作線索 |
| `scheduled` | 盤點日尚未考試 | 考後追蹤官方公告 |
| `superseded` | 官方舊版樣題已被新版取代 | 保留版本與重複題稽核，不直接計入目標 |

每科另有五個獨立數字：

- `expectedCount`：官方文件實際題數。
- `importedCount`：已轉成本站題目資料的題數。
- `answerVerifiedCount`：已逐題對照官方答案的題數。
- `explanationDraftCount`：已有自編詳解初稿的題數。
- `explanationReviewedCount`：詳解已完成人工複核的題數。

不得用「已匯入」代替「答案已核對」，也不得用「有詳解初稿」代替「詳解已複核」。
