## 狀態定義

| `availability` | 意義 | 後續動作 |
| --- | --- | --- |
| `published` | 官方 PDF 已找到且題數已核對 | 擷取、逐頁校對、匯入、寫詳解 |
| `not-found` | 考試已舉行，但官方歷屆考題頁沒有該科試題 | 定期重查官方；第三方只作線索 |
| `scheduled` | 盤點日尚未考試 | 考後追蹤官方公告 |
| `superseded` | 官方舊版樣題已被新版取代 | 保留版本與重複題稽核，不直接計入目標 |

每科另有五個獨立數字：

- `expectedCount`：官方文件實際題數。
- `importedCount`：已轉成本站題目資料的題數。
- `answerVerifiedCount`：已逐題對照官方答案的題數。
- `explanationDraftCount`：已有自編詳解初稿的題數。
- `explanationReviewedCount`：詳解已完成人工複核的題數。

不得用「已匯入」代替「答案已核對」，也不得用「有詳解初稿」代替「詳解已複核」。
